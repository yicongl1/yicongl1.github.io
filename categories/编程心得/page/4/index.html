无人机调试

这篇记录 Jetson Nano 与地面站（虚拟机 Ubuntu）通过 ROS 组网的调试过程。 一、前期准备 名词约定 地面站：开发者个人电脑上的 Ubuntu 虚拟机。 Nano：Jetson Nano 上的 Ubuntu 系统。 打开终端快捷键：Ctrl + Alt + T 连接局域网 开启路由器，将 Nano 和地面站接入同一个局域网。 把 Nano 和地面站接入同一个 Wi-Fi；图中是当时现场使用的 NETGEAR99 网络。 虚拟机网络设置 在 VMware 中关闭虚拟机 Ubuntu，打开「虚拟机设置 → 网络适配器 → 网络连接」，选择 桥接模式，并勾选「复制物理网络连接状态」。 桥接模式下，虚拟机会像一台独立设备一样出现在局域网里，Nano 才能直接访问它。 VMware → 虚拟机设置 → 网络适配器 → 桥接模式 → 复制物理网络连接状态 VMware 虚拟机设置：网络适配器选择「桥接模式」，并勾选「复制物理网络连接状态」。 二、获取 IP 地址和设备名称 IP 地址 在 Nano 上打开终端，输入： ifconfig 找到 wlan0 对应的 inet 地址。假设为 192.168.1.2，下文简称 NanoIP。
