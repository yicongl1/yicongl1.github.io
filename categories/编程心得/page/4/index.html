【网站搭建】Hugo 配置

记录第一次用 Hugo 搭静态站的流程。 前期准备 1）安装 Go 从 All releases - The Go Programming Language 下载 .msi 安装包，安装到选定目录。 在终端输入： go version 能输出版本号就说明安装成功。 2）安装 Hugo 从 gohugoio/hugo Releases 下载 Hugo，把 hugo.exe 所在目录加入系统环境变量 Path。 验证： hugo version 网站部署 1）创建一个新网站 hugo new site page-name 2）配置主题 在 Hugo Themes 里挑一个主题，然后在网站目录中执行： cd page-name git init git submodule add <主题仓库地址> themes/<主题名> 用 VS Code 打开网站目录，在配置文件 hugo.toml（旧版本是 config.toml）中写入： theme = "theme-name" 现在 Hugo 默认生成 hugo.toml；如果主题文档写的是 config.toml，两者作用相同，选一个即可。 3）添加内容 hugo new posts/post-name.md Markdown 语法可以看 Markdown 官方教程。

    【网站搭建】短代码、面包屑与目录结构

    短代码（shortcode） 短代码是 Hugo 提供的模板化片段，可以在 Markdown 里直接调用。 参考：https://stack.jimmycai.com/writing/shortcodes 视频插入 {{< youtube VIDEO_ID >}} {{< bilibili VIDEO_ID PART_NUMBER >}} {{< tencent VIDEO_ID >}} youtube 的参数是视频 ID，例如 https://www.youtube.com/watch?v=ZFL09qhKi5I 里的 ZFL09qhKi5I bilibili 的第一个参数是 BV 号或 av 号，第二个参数是分 P，省略时默认第 1 P tencent 的参数是腾讯视频的 vid 如果页面在国内访问，YouTube 的 iframe 可能加载不出来；这种情况下换成 bilibili 短代码更稳。 图标插入 iconify 把 iconify-icon.min.js 放到 assets/plugins/iconify/ 下，然后在 config.toml 里注册： [[params.plugins.js]] link = "plugins/iconify/iconify-icon.min.js" 之后可以在 Markdown 里直接使用： <iconify-icon icon="simple-icons:bilibili"></iconify-icon> icons8 / Line Awesome 在 config.toml 里配置社交图标： [[params.social]] icon = "lab la-github" # https://icons8.com/line-awesome url = "https://github.com/podcast-of-engineers" 模板里这样渲染：

      Git 使用学习

      本文参考资料 Git 概述 Linus 团队开发的分布式版本控制工具。每台电脑都有完整的版本库，另有一个共享版本库，因此不容易因为单点故障而宕机。 优势：备份、代码还原、协同开发、追溯问题代码的编写人和编写时间、无需中心服务器。 下载地址：https://git-scm.com/download Git GUI：Git 图形界面工具 Git Bash：Git 命令行工具 Git 基本配置 右键打开 Git Bash 设置用户信息 git config --global user.name "Solal" git config --global user.email "solal2600@gmail.com" 查看用户信息 git config --global user.name git config --global user.email 设置指令别名 # 创建 bashrc 文件 touch ~/.bashrc # 输出 git 提交日志 alias git-log='git log --pretty=oneline --all --graph --abbrev-commit' # 输出当前目录所有文件及基本信息 alias ll='ls -al' # 运行 bashrc 文件 source ~/.bashrc 解决 Git Bash 乱码 # 在 Git Bash 中执行 git config --global core.quotepath false # 在 ${git_home}/etc/bash.bashrc 文件最后加入下面两行 export LANG="zh_CN.UTF-8" export LC_ALL="zh_CN.UTF-8" Git 基本工作流程 git init（初始化） 初始化当前目录为一个本地 Git 仓库。完成后当前目录下会多一个 .git 隐藏文件夹。

        无人机调试

        这篇记录 Jetson Nano 与地面站（虚拟机 Ubuntu）通过 ROS 组网的调试过程。 一、前期准备 名词约定 地面站：开发者个人电脑上的 Ubuntu 虚拟机。 Nano：Jetson Nano 上的 Ubuntu 系统。 打开终端快捷键：Ctrl + Alt + T 连接局域网 开启路由器，将 Nano 和地面站接入同一个局域网。 把 Nano 和地面站接入同一个 Wi-Fi；图中是当时现场使用的 NETGEAR99 网络。 虚拟机网络设置 在 VMware 中关闭虚拟机 Ubuntu，打开「虚拟机设置 → 网络适配器 → 网络连接」，选择 桥接模式，并勾选「复制物理网络连接状态」。 桥接模式下，虚拟机会像一台独立设备一样出现在局域网里，Nano 才能直接访问它。 VMware → 虚拟机设置 → 网络适配器 → 桥接模式 → 复制物理网络连接状态 VMware 虚拟机设置：网络适配器选择「桥接模式」，并勾选「复制物理网络连接状态」。 二、获取 IP 地址和设备名称 IP 地址 在 Nano 上打开终端，输入： ifconfig 找到 wlan0 对应的 inet 地址。假设为 192.168.1.2，下文简称 NanoIP。
