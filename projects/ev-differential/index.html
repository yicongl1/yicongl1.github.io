团队创新竞赛项目

双电机分布式驱动与电子差速

上海大学 · 中欧工程技术学院「云创中欧」创新竞赛（2021–2022）

用左右后轮独立驱动替代机械差速器：Arduino Uno + L298N + 两个 TT 电机构建后驱模型小车，pygame 动画演示转弯时内外轮速差，并整理竞赛论文、技术路线与 Keras 回归示例。

项目背景

机械差速器解决的问题很具体：汽车转弯时，外侧车轮走的弧线更长，内侧车轮走的弧线更短。如果左右轮被一根刚性轴锁死，只能以同一转速转动，轮胎就会在地面上“蹭”——轻则磨损，重则影响操控。

分布式驱动给出了另一种答案：左右后轮各用一个电机独立驱动，用控制器调节两侧的转速，让它们按转弯半径各走各的。这就是电子差速。

这是上海大学中欧工程技术学院 2021–2022 年「云创中欧」创新竞赛作品。项目从方案调研开始，做了三件事：用 pygame 把差速关系可视化，用 Arduino 搭一台能跑的后驱模型小车，再用一个 Keras 回归示例验证神经网络建模流程。

方案

项目先比较了三种驱动布局：

  • 集中式驱动：单电机 + 机械差速器，结构成熟，但差速关系被机械结构固定；
  • 轮毂电机分布式驱动：每个车轮独立驱动，控制自由度最高，成本和簧下质量也最高；
  • 双电机分布式驱动：左右后轮各一个电机，保留前轮转向，用软件实现差速，是模型小车上最现实的折中。

最终选择双电机后驱 + 前轮舵机转向：左右后轮由 L298N 的两路 H 桥分别驱动，MG995 舵机控制前轮转角，红外遥控给出前进、后退、左转、右转指令。

原理

在低速、忽略轮胎侧偏的假设下，可以用阿克曼转向的简化模型描述转弯：

R = L / tan(δ)
v_inner = v · (R - B/2) / R
v_outer = v · (R + B/2) / R

其中 L 是轴距，B 是轮距，δ 是前轮转角，R 是后轴中心的转弯半径。内外轮速比只由几何决定：

v_outer / v_inner = (R + B/2) / (R - B/2)

模型小车的轴距约 0.16 m、轮距约 0.12 m。以 30° 转角计算，R ≈ 0.277 m，内外轮速比约 1.55；如果车速是 1 m/s，内侧轮约 0.78 m/s，外侧轮约 1.22 m/s。代码里没有编码器，也没有闭环，实际做法是把这组关系翻译成固定占空比：直行时左右都是 180，左转时内侧 120、外侧 180，右转反过来。

实现

  • 控制器：Arduino Uno，analogWrite 输出 PWM 到 L298N 的 IN1–IN4；Servo 库驱动 MG995，转角取 45° / 90° / 135°。
  • 遥控：HX1838 红外接收器接 D3，使用 IRremote 2.x 的 IRrecv / decode_results 旧 API；串口以 9600 打印键值，便于核对。
  • 供电：两节 18650 接 L298N 的 12V / GND，Arduino 与 L298N 共地；舵机建议单独 5V 供电，避免电机启动时把舵机拉抖。
  • 可视化：pygame 动画把四个车轮的转速映射为颜色深浅，转弯时给出方向箭头和车轮转角；版本从 v1.0 的颜色映射，迭代到 v2.0 的公路背景与随转角旋转的车轮。
  • 文档：竞赛论文、立项与技术路线、电子差速调研、红外与舵机调试笔记、模型小车制作总结都在 docs/。

结果与局限

这台小车能完成前进、后退、左转、右转和停车，pygame 动画能把“转弯时内外轮不一样快”直观地演示出来。它适合做原理教学和方案验证，但不是一台完整的电子差速控制器：

  • 没有轮速传感器，PWM 是开环给定，电池电压下降、地面摩擦变化都会让实际轮速偏离设定；
  • 前轮转角由舵机开环控制，没有转角反馈；
  • 没有电流环、速度环或横摆角速度闭环，不能处理打滑和载荷转移；
  • Keras 示例用的是 Boston Housing 数据集，只验证回归网络的训练流程，并没有用实车差速数据训练。

如果要往下走，最小的闭环版本是：后轮加编码器，做左右轮速 PID；前轮加电位器或角度传感器；用舵机转角实时计算目标轮速比，而不是查固定的 120/180 表。
