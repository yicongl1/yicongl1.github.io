个人学习项目

Unity 游戏开发学习作品集

2021 - 2022 · 4 个 Unity 原型 + 8 个 C# 练习

收录 4 个 Unity 原型（滚球街机合集、飞龙射击、变色跑酷、角色移动）与 8 个 C# 控制台练习，覆盖 Rigidbody 物理、碰撞与触发器、UGUI、场景管理、协程、Animator、粒子与音频；三个 Windows 构建可从 GitHub Releases 下载。

项目背景

2021 到 2022 年，我从 C# 基础和 Unity 入门开始，逐步完成了 4 个可玩的 Unity 原型和 8 个 C# 控制台练习。它们大多始于教程和课堂练习，后来加入了关卡、UI、状态机、粒子、音效和自己的玩法调整。

这个仓库的目的不是展示“完成度”，而是把学习轨迹留下来：遇到什么问题、用了哪个 API、后来怎么改。

四个 Unity 原型

  • 滚动球街机合集(3D / 多场景)：用主菜单串联三个小游戏——滚球闯关、迷宫、拉箱子解谜，另含第一人称控制器演示。练习了 Rigidbody 速度与力的区别、OnTriggerEnter / OnCollisionEnter、SceneManager 场景切换、Time.timeScale 暂停、协程和 UGUI。
  • 飞龙射击(2D / 竖版射击)：玩家移动与连发冷却、随机刷怪、受击闪红与爆炸、Boss 巡逻状态机、按屏幕比例调整正交摄像机。练习了 Instantiate / Destroy、2D 触发器、Mathf.Clamp 和材质 UV 动画。
  • 变色跑酷(3D / 无限跑酷)：自动前进，Space 跳跃，J 在红/绿之间换色；颜色与脚下平台不一致即死亡。练习了 Rigidbody.velocity、碰撞标签、Animator、粒子预制体和单例式 GameMode。
  • 角色移动(3D / 角色控制)：最小化的第三人称 Demo，用 Input.GetAxis 组合世界坐标方向，transform.LookAt 控制朝向，再按 speed * Time.deltaTime 位移。

C# 基础练习

8 个独立的 .NET Framework 4.7.2 控制台项目，覆盖：

  • 单例管理器、对象数组、拳击对战
  • 一维/二维数组、List 的遍历与原地删除
  • 对象复制、构造函数与命名参数
  • 按权重抽卡与累计概率
  • 回合制战斗、技能状态、伤害与持续治疗
  • Dictionary 的增删改查与遍历时安全删除
  • 类与对象、状态约束、简单交互菜单

运行与下载

三个游戏已打包为 Windows 64 位版本，放在仓库的 release-assets/，也发布在 GitHub Releases。下载解压后双击 .exe；如果 Windows 弹出 SmartScreen，选择“更多信息 → 仍要运行”。

Unity 工程建议用 Unity Hub 安装 2021.3 LTS 打开；C# 练习用 Visual Studio 打开 csharp-exercises/CSharpExercises.sln 可一次加载全部 8 个项目。

说明

  • 工程保留了 Assets、Packages、ProjectSettings，Library、Temp 等生成目录不提交。
  • 项目基于旧版 Input Manager（Input.GetAxis），没有使用新 Input System。
  • 部分脚本保留了学习阶段的注释、调试代码和未使用字段，逻辑以可运行和可读为主。
  • 工程中使用的第三方素材（第一人称控制器、角色模型、特效与音效等）版权归原作者所有，不在仓库代码的授权范围内。
