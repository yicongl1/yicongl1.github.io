个人项目

个人网站：一台持续运行的小型出版机

Hugo + Toha · 中 / 英 / 法三语

用 Hugo 维护的三语静态站：数据驱动的首页、带成绩与学分互链的学业档案、项目与竞赛详情页、giscus 评论、阅读进度与滚动动效，以及能把主页数据直接排成 A4 PDF 的 /cv/ 简历生成器。

2024 - 至今 Hugo · Git

为什么自己做

用模板站也能放简历，但我想要的是「内容和排版分开」：同一份教育、项目、竞赛数据，首页是一种视图，学业档案是一种视图，简历是第三种，博客是第四种。改一次数据，几处同时更新——这件事只有自己写才能做到。

网站从 2024 年 4 月开始，最初是一套简单主题，后来换到 Toha，并逐步把首页、项目页、竞赛页、学业档案都改造成数据驱动的结构。今天它是一个三语、无后端、可以在手机上读完的完整作品集。

怎么把信息组织清楚

首页是一份可滚动的简历

首页不是一堆卡片，而是一条有意设计的阅读顺序：关于 → 技能 → 经历 → 教育 → 项目 → 竞赛 → 链接。每一段都能独立存在，但连起来读就是一份完整的个人介绍。所有段落按 weight 排序，改顺序只需要改数字。

两级结构：列表负责概览，详情负责展开

项目、竞赛、学业档案都是「列表页 + 详情页」：

  • 列表页给出筛选按钮（全部 / 学术 / 编程 / 科普），一屏内看懂方向；
  • 详情页统一模板：面包屑导航、标题与摘要、事实侧栏（课程、时间、角色）、相关文章、相关技能、评论区。

这样浏览者永远知道自己在哪里、能往哪走，不需要在长页面里迷路。

一致的视觉语言

全站沿用同一套颜色、字号与间距：板块标题带下划线、日期右对齐且用等宽数字、卡片悬停有轻微位移。深色模式不是简单反色，而是重新定义了一组 CSS 变量——遮罩、文字、边框各自有对应的深色值。

用 Hugo 搭建

  • 生成器：Hugo（extended），部署为纯静态文件，没有任何后端；
  • 主题：Toha 作为基础，再用 layouts/ 覆盖它的项目、竞赛、学业档案、简历等页面；
  • 数据：首页各板块、学业档案都在 data/ 里，用 YAML 描述，模板只负责组合；
  • 内容：博客文章是 Markdown，支持自定义 shortcode（图片、引用、视频）；
  • 资源处理：图片按宽度缩放、CSS/JS 走 Hugo Pipes 的 minify + fingerprint，线上缓存永远是新的。

这套结构的直接好处是：加一门课、加一个项目、换一张图，都只是改数据，不需要碰模板。

站内的几个功能

学业档案

两所学校各有一份完整的课程档案：

  • 按学期排列课程，列出课程代码、成绩、GPA 与 ECTS 学分；
  • 成绩自动分档配色：90 分以上、80–89、70–79、70 以下各用一种颜色，A/B/C 等级同样处理；
  • 课程代码是锚点（如 #course-UR06），项目详情页可以直接跳到对应课程；
  • 课程、课程项目、竞赛之间互相链接，从一张成绩单能一路点到无人机竞赛页。

项目详情

每个项目页面包含：课程与时间、我的角色、仓库链接（公开仓库直接给出，源码仓库保持私有）、相关文章列表、相关技能，以及页尾评论区。相关文章把同一个项目的技术复盘、踩坑记录串在一起。

竞赛详情

竞赛页面更强调「结果」：奖项、时间、角色放在页头，下面是比赛背景、我负责的部分，以及证书画廊——点击证书可以放大查看。同一个比赛的多篇文章也在页面底部列出。

链接与动态

首页的链接区汇总 GitHub、Gitee、CSDN、LeetCode、洛谷、LinkedIn；贡献热力图和最近活动时间线让访客一眼看到「最近在做什么」，而不只是静态的简历条目。

交互与动效

为了「读起来舒服」做了一些不喧宾夺主的细节：

  • 阅读进度条固定在页面顶部，随滚动填充；
  • 回到顶部按钮在滚动 520px 后淡入；
  • 正文块在进入视口时轻微上浮入场（IntersectionObserver），并且尊重系统的「减少动态效果」设置——打开后所有动画自动关闭；
  • 代码块右上角有复制按钮，点击后短暂显示「已复制」。

评论区

纯静态站点没有服务器，评论存进 GitHub Discussions：giscus 只加载一个 iframe。评论区的主题跟随站点的深浅色切换，文章、项目、竞赛页都可以留言。

简历生成器

/cv/ 是站内最「重」的页面：勾选语言与条目，右侧实时预览 A4 分页，点一下导出可点击的 PDF；也可以粘贴岗位描述，按关键词自动重排条目。数据全部来自首页 YAML，英法版本会自动把站内链接指向对应语言页面。实现细节见这篇文章。

三语与发布

站点有中文、英文、法文三个版本：翻译文件按 *.en.md、*.fr.md 并列，数据目录按 data/<lang>/ 分开，导航里的语言专属内容统一标注 (Chinese) / (Chinois)。首次访问会按浏览器语言自动跳转，但只认浏览器语言——不用 IP 猜测，因为 VPN 和出差会让 IP 说谎。

发布流程刻意分成两个仓库：

  • 私有仓库保存 Hugo 源码与全部内容；
  • 公开仓库只接收构建产物：推送到私有仓库的 main 后，GitHub Actions 重新构建、加密，再把产物压成单次提交强推；本地保留一份同样的脚本作兜底。

源码仓库不公开，但成品与评论数据都可以直接查看：

  • 发布仓库（GitHub Pages） —— 线上页面就是它构建出来的；
  • 评论仓库（giscus） —— 所有文章与项目页的评论都存成这里的 Discussions。

这样公开的 GitHub Pages 仓库里不会暴露草稿和脚本细节，而源码历史保持完整。

收获

做站最直接的收获是：所有「顺手」的功能，背后都是对数据结构的坚持。首页数据如果当初写成大段 HTML，就不会有后来的学业档案互链、简历生成器和三语页面。

另一个收获是工程习惯：构建脚本、发布脚本、资源指纹、编码坑（Windows 控制台、PowerShell、YAML 里的冒号与 &），每一条都留下了记录，也都写进了这个站点的文章里。

网站还在长：接下来想做中文分词的全站搜索、更多简历排版模板，以及把每年的阅读记录整理成可以回看的时间线。
