团队课程项目（2 人）

敦刻尔克热浪敏感性

贡比涅技术大学 · UR06 地理信息学（2023 秋）

用 ArcGIS 把“城市为什么热”拆成建筑致热、植被降温、水体降温三个连续场，通过两次核密度与多准则加权得到敦刻尔克的热浪敏感性指数；建筑效应约为植被的 3.3 倍、水体的 55 倍。

项目背景

这是 UTC UR06「地理信息学」 的课程项目（A23），两人小组完成。题目要求只用原始地理图层(BD TOPO、ADMIN EXPRESS、Enedis、CORINE)，不能使用现成的热岛或 LCZ 图层，在 ArcGIS 里完成从矢量处理到栅格分析的完整链路，最终交付一张敦刻尔克的热浪敏感性地图和一份约 20 页的报告。

项目原报告已经丢失。仓库里的文档是依据 .mxd 工程、shapefile、栅格统计和当时的对话重建的；每个要素都标注了 [C] 已确认 / [D] 推断 / [待补]。

数据

  • BD TOPO（IGN）：建筑 43,912 栋、植被 1,131 区、水面 626 处、水系 254 + 307 段、潮间带与海陆界线；
  • ADMIN EXPRESS：市镇边界与人口；
  • Enedis / 开放数据：42 个 IRIS 的用电量，连接后计算单位面积用电密度；
  • CORINE Land Cover 1990 / 2000 / 2006 / 2012：用于历时分析，人工化比例从 74.2% 升到 78%。

方法

  1. 统一投影到 RGF93 / Lambert 93(EPSG:2154，单位米)，否则面积和距离没有意义；
  2. Union + Feature To Point：每栋建筑、每块绿地只贡献一次，权重取自身面积；
  3. 两次核密度(小半径 + 大半径)：单一核密度只能得到“钟形”，无法同时表达“贴身处强”和“远处弱”，两次组合才形成随距离衰减的梯度；
  4. 掩膜裁剪到市镇边界；
  5. 归一化 + 取反 + 加权(多准则分析)：
S = 0.50 · B* + 0.33 · (1 - V*) + 0.17 · (1 - E*)

建筑是“加剧型”，植被和水体是“缓解型”，所以后两者必须取反；否则植被越多，算出的敏感性反而越高——这是多准则分析里最常见的符号错误。

结果

三幅梯度栅格的实测统计（直接读自随栅格交付的 .aux.xml）:

栅格像元最大值平均值
建筑热效应35.5 m0.06190.00754
植被降温33.5 m0.01900.00438
水体降温44.4 m0.00110.00015

建筑的最大效应是植被的 3.3 倍、水体的 55 倍。 敦刻尔克是一个建筑主导、植被碎片化、水体局地化的领土：78% 的地表已人工化，其中 39% 是工业与交通用地。

敏感性最高的区域集中在密集市中心、港口工业带和大型设施周边；最低的是大型水池、沙丘与潮间带、南部农业边缘。报告里最关键的结论不是“哪里热”，而是哪里缺少补偿：建筑效应高、植被又低的区域同时承受两个惩罚项，才是公共决策应该优先处理的地方。

局限

  • 原报告丢失，docs/ 是重建文本；权重（0.50 / 0.33 / 0.17）和核密度参数（搜索半径、核函数）没有被保存，现在是“可辩护的重建值”，不是原始值；
  • 三幅栅格的像元大小不一致(35.5 / 33.5 / 44.4 m)，直接组合会触发隐式重采样——这是原作业的真实缺陷，已在报告里作为批判点写出；
  • 图是用栅格重新渲染的，不是当时 ArcMap 版面的导出；
  • 没有现场验证，指数是静态的，不考虑人口暴露与行为。
