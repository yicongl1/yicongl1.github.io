BEST：多尺度领土均衡与城市福祉

贡比涅技术大学 Avenues 实验室（EA 7284）· TN09 毕业实习

时间2024.09 - 2025.02 我的角色研究助理工程师 机构UTC · Avenues (EA 7284)

代码仓库 ↗ 学术档案 →

项目背景

这是我在 UTC Avenues 实验室（EA 7284） 完成的 TN09 毕业实习，参与 BEST 项目——为“领土系统均衡”构建理论基础，并准备一个面向规划者与决策者的多尺度决策支持工具。

快速发展的城市地区普遍面临四重压力：交通饱和、领土不平等、城市化过快、住房成本高企。现有模型（城市动力学、多准则决策 MCDA、PSR/DPSIR 框架）通常把住房、交通、环境与经济割裂处理，缺少对领土系统的统一表征。

BEST 的目标是：

  • 构建“均衡”应用于领土系统的理论框架；
  • 刻画一个以居民福祉为最终标准的动态、多尺度领土均衡；
  • 为未来的决策支持工具准备概念模型、指标与数据基础。

我的工作

三份独立的系统综述、一套指标操作化工作，以及指标之间关系的定量探索。

1. PRISMA 系统综述

检索 Scopus、Google Scholar、HAL、PROSPERO，语种以法语和英语为主，时间优先近十年，用 Zotero 管理文献、注释和交叉引用。

流程遵循 PRISMA：识别研究 → 去重 → 标题/摘要筛选 → 全文阅读与纳入标准。每篇文章按“相关 / 部分相关 / 不相关”分类并记录理由。

主题分析篇数引导问题
领土系统360领土如何组织？在哪些尺度上？
福祉120居民福祉由哪些维度构成？

2. 指标体系

  • 领土系统：Agenda 21 的 134 项城市可持续指标，按经济、社会、环境、制度四个维度分类，再补充 INSEE、ADEME、eaufrance、ATMO France 等法国机构指标。
  • 福祉：OECD Better Life Index 的 11 个维度——住房、收入、就业、社区、教育、环境、公民参与、健康、生活满意度、安全、工作与生活平衡；区分客观指标（如凶杀率）与主观指标（如夜间独行的安全感）。

每行指标都记录定义、官方来源和计算方法，让后续工具可以直接实现。

3. 相关性分析

目标：检查指标体系的内部一致性，找出应纳入模型的相互依赖。

OECD CSV（长表） → 透视成 国家 × 指标 → Pearson 相关矩阵
                  → seaborn 热力图 → 按国家组比较

几个代表性关系：

关系r解读
预期寿命 ↔ 缺乏基础设施的住房−0.85卫生设施不足会削弱健康基础
个人收入 ↔ 生活满意度+0.80主观福祉与财务稳定性高度相关
失业率 ↔ 技能水平−0.68资质与就业能力相关

一个异常被原样保留：水质与就业率、生活满意度出现较强相关。它更可能是样本结构造成的，而不是因果机制；这类异常是后续建模需要解释的对象。

4. 概念建模

把 Forrester（1969）的城市动力学（人口 / 住房 / 经济活动三个子系统及反馈回路）、MCDA、PSR / DPSIR 与敏感性模型组合起来，形成多尺度框架。

工具：Vensim（系统动力学）、ArcGIS（空间分析与制图）、Python（指标处理）、Excel（指标表）。

结果

  1. 一个结构化的 560 篇文献 corpus 和三份概念综述，明确领土系统、福祉与均衡的定义及联系。
  2. 两套可直接使用的指标体系，含官方来源与计算方法，为后续工具提供量化基础。
  3. 一份可复现的相关性分析（代码、数据、图），说明多数 Better Life Index 指标之间的关系符合预期，并隔离出异常案例。
  4. 对 BEST 项目概念框架与决策支持算法的贡献。

局限

  • 语料以英语为主，法语文献是补充使用，不是系统覆盖。
  • 相关不等于因果：分析是探索性的，没有显著性检验，也没有控制混杂变量。
  • 缺失值按原分析口径填 0，可能对指标不完整的国家产生偏差。
  • 指标之间量纲、单位和时间尺度仍不统一；把它们聚合成单一指数不是这次实习的任务。
