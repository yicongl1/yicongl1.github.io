Projet d'apprentissage personnel

Portfolio d'apprentissage Unity

2021 - 2022 · 4 prototypes Unity + 8 exercices C#

Quatre prototypes Unity (arcade de billes, shoot'em up, runner de couleurs, déplacement de personnage) et huit exercices C# en console, couvrant la physique Rigidbody, les collisions et déclencheurs, UGUI, la gestion de scènes, les coroutines, Animator, les particules et l'audio. Trois builds Windows sont disponibles dans GitHub Releases.

Contexte

Entre 2021 et 2022, je suis parti des bases du C# et de l’initiation à Unity pour arriver à quatre prototypes jouables et huit exercices C# en console. La plupart sont nés de tutoriels ou d’exercices de cours, puis se sont enrichis de niveaux, d’UI, de machines à états, de particules, de sons et d’ajustements de gameplay.

Le but de ce dépôt n’est pas de montrer un produit fini, mais de garder la trace de l’apprentissage : quel problème s’est posé, quelle API l’a résolu, et comment le code a évolué ensuite.

Les quatre prototypes Unity

  • Collection arcade de billes (3D / multi-scènes) : un menu principal relie trois mini-jeux — parcours de billes, labyrinthe et puzzle de caisse à tirer — ainsi qu’une démo de contrôleur à la première personne. Travail sur la différence entre vitesse et force d’un Rigidbody, OnTriggerEnter / OnCollisionEnter, les transitions SceneManager, la pause via Time.timeScale, les coroutines et UGUI.
  • Shoot’em up de dragon (2D / tir vertical) : déplacement avec temps de recharge, apparition aléatoire des ennemis, flash de dégâts et explosions, machine à états de patrouille du Boss, caméra orthographique adaptée au ratio de l’écran. Travail sur Instantiate / Destroy, les déclencheurs 2D, Mathf.Clamp et le défilement d’UV.
  • Runner de couleurs (3D / endless runner) : le personnage avance seul, Espace saute, J alterne rouge et vert ; une plateforme de l’autre couleur est mortelle. Travail sur Rigidbody.velocity, les tags de collision, Animator, les prefabs de particules et un GameMode en singleton.
  • Déplacement de personnage (3D / contrôleur) : une démo troisième personne minimale — Input.GetAxis construit une direction en coordonnées monde, transform.LookAt fixe l’orientation, puis le personnage avance de speed * Time.deltaTime.

Les bases du C#

Huit projets console autonomes en .NET Framework 4.7.2 :

  • gestionnaires singleton, tableaux d’objets, combat de boxe
  • tableaux 1D/2D et filtrage de List sur place
  • copie d’objets, constructeurs et arguments nommés
  • tirages gacha pondérés et probabilités cumulées
  • combat au tour par tour, états de compétences, dégâts et soins dans le temps
  • opérations sur Dictionary et suppression sûre pendant l’itération
  • classes, contraintes d’état et petit menu interactif

Lancer et télécharger

Trois jeux sont empaquetés en builds Windows 64 bits dans release-assets/ et publiés dans GitHub Releases. Décompressez puis lancez le .exe ; si SmartScreen apparaît, choisissez « Informations complémentaires -> Exécuter quand même ».

Pour les projets Unity, installez 2021.3 LTS via Unity Hub. Les exercices C# se chargent ensemble depuis csharp-exercises/CSharpExercises.sln dans Visual Studio.

Remarques

  • Les projets conservent Assets, Packages et ProjectSettings ; les dossiers générés comme Library et Temp ne sont pas versionnés.
  • Ils utilisent l’ancien Input Manager (Input.GetAxis), pas le nouvel Input System.
  • Certains scripts gardent des commentaires, du code de débogage et des champs inutilisés de la période d’apprentissage ; la priorité est un code lisible et exécutable.
  • Les ressources tierces (contrôleur première personne, modèle de personnage, effets et sons) restent sous leurs licences d’origine et ne sont pas couvertes par la licence du code du dépôt.
