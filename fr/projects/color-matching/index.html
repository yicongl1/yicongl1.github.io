Mise en couleur informatique : K-M à constante unique et recherche multi-départs

Huashu Cup 2023, problème B · coloration de produits opaques

Des spectres K/S à l'écart CIELAB, transformer « retrouver cette couleur » en une recherche sous contrainte. Le dépôt corrige la normalisation XYZ absente du rapport original, utilise les courbes K/S mesurées comme modèle direct, et combine échantillonnage multi-départs et descente par coordonnées pour les recettes Q2, le coût Q3 et le nombre minimal de colorants Q4.

août 2023 Python · NumPy · Colorimétrie · Optimisation

Le sujet

Le problème fournit les valeurs K/S de trois colorants (rouge, jaune, bleu) à huit concentrations de 0,05 % à 5 %, tous les 20 nm de 400 à 700 nm, ainsi que la réflectance de dix échantillons cibles. Quatre questions :

  1. ajuster K/S en fonction de la concentration à chaque longueur d’onde ;
  2. proposer dix recettes différentes par cible avec ΔE < 1 ;
  3. ajouter le coût pour un lot de 2 kg ;
  4. utiliser le moins de colorants possible tout en gardant ΔE < 1.

De la couleur au K/S

Chaque réflectance mesurée devient K/S = (1 - R)² / (2R). Un ajustement linéaire K/S = a·c + b est calculé par colorant et par longueur d’onde. Sur les 48 ajustements, le R² moyen vaut 0,9965 et le minimum 0,9258 (rouge à 700 nm).

La première erreur du rapport original

Le passage de la réflectance aux XYZ exige une normalisation :

X = k · Σ S(λ)x̄(λ)R(λ)Δλ, avec k = 100 / Σ S(λ)ȳ(λ)Δλ

La première version intégrait par Simpson puis multipliait par 0,1, sans k. Les XYZ étaient environ dix fois trop grands et L* dépassait 100 — impossible en CIELAB. Ce dépôt applique la normalisation ; les dix cibles ont maintenant un L* entre 71 et 86.

Pourquoi le modèle direct utilise les courbes mesurées

Utiliser seulement la pente de l’ajustement et le K/S du substrat sous-estime les faibles concentrations : à 400 nm, le rouge mesure 0,637 à c = 0,05 %, alors que base + pente × 0,05 donne 0,075. L’ordonnée à l’origine de l’ajustement n’est pas le substrat ; la courbe se redresse.

L’optimiseur interpole donc directement les courbes K/S mesurées :

K/S_mix = Σ K/S_i(c_i) − (n − 1)·K/S_base

Pour un seul colorant, la courbe mesurée est reproduite exactement ; pour un mélange, l’additivité du K/S est supposée. Ce n’est pas parfait, mais bien plus proche des données que l’ajustement linéaire.

Recherche

Trois concentrations se projettent sur trois composantes Lab : la région ΔE < 1 est petite et irrégulière. La chaîne est :

  1. départs aléatoires log-uniformes (1e-5–5 %) et grilles creuses à un ou deux colorants ;
  2. évaluation par lots du ΔE, conservation des départs faisables ;
  3. descente par coordonnées sur les meilleurs départs, pas divisé par deux à partir de 0,05 ;
  4. filtre de diversité dans l’espace des concentrations pour que les dix recettes soient réellement différentes.

Q2 classe par ΔE, Q3 par coût pour 2 kg parmi les candidats ΔE < 1, et Q4 essaie un, deux puis trois colorants en gardant le premier nombre faisable.

Résultats

  • Q2 : 80 des 82 recettes retournées ont ΔE < 1 ; huit cibles sur dix donnent dix recettes distinctes.
  • Q3 : 79/82 faisables ; la recette la moins chère pour 2 kg coûte 0,31 CNY de colorant.
  • Q4 : les cinq premières cibles exigent trois colorants ; les recettes à deux colorants sont infaisables avec ce modèle.

Ce que j’en retiens

  • Corriger les unités avant d’optimiser. Une normalisation manquante rend tous les écarts de couleur faux, tout en restant plausible à la lecture.
  • Le choix du modèle compte plus que l’algorithme. L’ajustement linéaire a un beau R² mais se trompe aux faibles concentrations ; les courbes mesurées font apparaître des recettes faisables.
  • Aléatoire + recherche locale battent une grille quand la région faisable couvre six ordres de grandeur.
  • Documenter les échecs. L’échantillon 6 n’atteint jamais ΔE < 1 ; le code et les CSV gardent feasible=False au lieu d’élargir le seuil.

Le code, les données, les tableaux de résultats et le rapport original sont dans le dépôt. La version narrative est dans cet article.
