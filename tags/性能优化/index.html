把一张壁纸引擎作品搬进网页：拆包、音频与 canvas 动效

Wallpaper Engine 上有几张很安静的壁纸：一张雨夜的油画，一张海面上的油画。静止看只是画，动起来靠的是几层很轻的东西——雨丝、水波、颗粒、偶尔一道远处的闪电。 想把它们搬进网页。不是放一段循环视频，而是用 canvas 把动效重新画出来：可以自适应屏幕、能跟着滚轮和鼠标呼吸、手机上也不至于烧电池。这篇文章记录拆包、取音频和复刻动效的整个过程。 一、拆包：.pkg 里有什么 Wallpaper Engine 的工程被打包成 scene.pkg，本质是一个简单的容器： PKGV0022 | 文件数 | [名字长度 | 名字 | 偏移 | 大小] × N | 数据区 用 RePKG 能解出大部分内容，但遇到 PKGV0022 时它直接返回空。所以写了个几十行的解析器：读 magic、读数量、按表逐个取名字和区间，然后把数据区切成独立文件。 里面主要是三类东西： .tex 纹理（需要再解一次才还原成 png）； .json 场景描述（每个图层的位置、缩放、动效参数）； 音频（音乐、环境声）。 纹理解码交给 RePKG，音频直接就是 mp3/ogg——这部分反而最好处理。 二、图片不是重点，动效才是 把原图铺满屏幕很简单：background-size: cover 加一个位置偏置。真正决定「像不像」的是叠加在上面的几层。 先看那张海面。壁纸里的水面一直在缓慢地扭曲，边缘有很轻的色散，整体颗粒感很重，画面还在轻微抖动。拆成四件事之后，每一件都不难： 1. 水波折射 把画面按横条切开，每一条按正弦波左右错位，再重新拼回去： for (let i = 0; i < strips; i++) { const y = i * h / strips; const off = Math.sin(y * 0.0052 + t * 0.9) * 6.4 + Math.sin(y * 0.019 - t * 1.55) * 2.6; ctx.drawImage(buffer, 0, sy, bw, sh, off, y, w, sh); } 横条不用很细，30 条就够——相邻条之间的位移差不到 1px，接缝看不出来。 2. 色散 把同一帧拆成红、绿、蓝三个缓冲（先用纯色填充、再用 multiply 叠上原图），然后三张各错开 3–5px 用 lighter 加回去。亮部边缘会自然浮出红蓝色边，暗部几乎没有——这正是真实镜头的样子。
