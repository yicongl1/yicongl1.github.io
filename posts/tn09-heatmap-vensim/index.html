从相关性热力图到系统动力学：BEST 项目的多尺度框架

    项目仓库：https://github.com/yicongl1/TN09-BEST-Territorial-Well-Being

    上一篇讲的是怎么从 560 篇文献里整理出两套指标。这一篇讲后半段：指标之间是什么关系，以及怎么把关系变成一个可以讨论的多尺度框架。

    先看相关性，但不要急着解释

    我用 OECD Better Life Index 的 22 个指标做了一张 Pearson 相关矩阵。数据是“国家 × 指标”的长表，透视后计算相关，再用 seaborn 画热力图。

    pivot = df.pivot(index="country", columns="indicator", values="value")
corr = pivot.corr(method="pearson")
sns.heatmap(corr, cmap="coolwarm", center=0, annot=True, fmt=".2f")

    几条强关系：

    关系r可能的解释
    预期寿命 ↔ 缺乏基础设施的住房−0.85卫生设施不足影响健康
    个人收入 ↔ 生活满意度+0.80财务稳定与主观福祉相关
    失业率 ↔ 技能水平−0.68资质与就业能力相关

    这些关系符合常识，可以作为“指标体系没有明显跑偏”的证据。但热力图只能告诉我们“一起变化”，不能告诉我们“谁导致谁”。

    一个异常值得保留：水质与就业率、生活满意度强相关。它更可能是国家样本结构造成的——高收入国家同时有更好的水质和更高的就业率。把这种关系直接写进模型，会得到错误的政策建议。

    相关性之后，为什么还需要系统动力学

    相关矩阵是静态的：它描述同一时点的变量关系，但没有反馈、存量和时间延迟。

    BEST 要讨论的是“领土系统均衡”，它至少包含三个互相影响的子系统：

    • 人口：迁移、年龄结构、住房需求；
    • 住房：供给、价格、空置；
    • 经济活动：就业、企业、通勤。

    Forrester 1969 年的城市动力学用存量、流量和反馈回路描述这些关系。我在 Vensim 里做的不是完整仿真，而是把关键变量和反馈方向画出来，作为概念模型的一部分：

    • 就业增加 → 人口流入 → 住房需求上升 → 房价上涨 → 人口流出；
    • 住房供给增加 → 房价下降 → 人口流入；
    • 交通拥堵 → 通勤成本上升 → 就业吸引力下降。

    这些回路不追求参数精确，它们的作用是让讨论从“指标列表”变成“机制假设”。

    ArcGIS 放在哪一步

    系统动力学处理时间，ArcGIS 处理空间。

    在 BEST 里，空间化至少有三个用途：

    1. 把指标放到具体领土单元上，而不是国家平均值；
    2. 观察相邻单元之间的溢出和差异；
    3. 为多尺度分析提供边界：市镇、跨市镇、省、大区、国家。

    概念上，这对应“多尺度”的核心：同一个均衡问题，在不同尺度上有不同的变量和政策杠杆。市镇层面关心住房和交通，区域层面关心就业和基础设施，国家层面关心再分配和法规。

    一个多尺度框架的骨架

    把上面的东西放在一起，框架可以粗略写成：

    领土系统
├── 子系统：人口 / 住房 / 经济 / 环境 / 治理
├── 指标：134 项可持续指标 + 本地数据源
├── 空间：ArcGIS 多尺度单元
├── 动态：Vensim 存量-流量-反馈
└── 评价：福祉 11 维度 + MCDA

    这个骨架还不是一个可运行的工具，但它定义了工具需要的数据、变量和评价标准。后续团队可以在这个骨架上继续做问卷、专家访谈和仿真。

    三个诚实的边界

    1. 相关不是因果

    热力图是探索性的，没有显著性检验，也没有控制混杂变量。它的价值是“提出假设”，不是“证明机制”。

    2. 指标不能直接相加

    134 项指标的量纲、单位和时间尺度都不同。要聚合成一个“均衡指数”，需要先做标准化、权重和敏感性分析；这次实习没有走到那一步。

    3. 模型不是决策

    Vensim 的回路图可以帮助讨论，但它不是预测工具。政策决策还涉及价值判断、预算、法律和利益相关者，模型只能提供一种结构化的视角。

    小结

    从 560 篇文献，到两套指标，再到相关矩阵、Vensim 回路和 ArcGIS 空间化，BEST 的工作更像是在搭一个“可以继续往上盖”的架子，而不是交付一个成品工具。

    这也让我更清楚一件事：数据分析的价值不只在算出结果，更在于把问题拆成可讨论的结构。
