转弯时内外轮到底差多少：电子差速的几何、公式与 PWM 映射

    项目仓库：https://github.com/yicongl1/EV-Electronic-Differential

    机械差速器存在了一百多年，原因很简单：转弯时外侧车轮走的路更长。如果左右轮被刚性轴锁成同一个转速，轮胎只能一边滚一边蹭。电子差速想做的事，是用两个独立电机复现“内外轮各走各的”，只不过把机械结构换成了控制代码。

    这篇只回答一个定量问题：给定轴距、轮距和前轮转角，内外轮到底应该差多少？然后把这个结果和模型小车里的 120/180 占空比对上。

    先把几何画出来

    把车简化成两轮模型：后轴中心到前轴的距离是轴距 L，左右轮中心距是轮距 B，前轮转角 δ。低速、忽略轮胎侧偏时，车辆绕一个瞬时中心转弯，后轴中心的轨迹半径是：

    R = L / tan(δ)

    内侧后轮的半径是 R - B/2，外侧后轮是 R + B/2。同一时间内，车轮走过的弧长与半径成正比，所以轮速也成正比：

    v_inner = v · (R - B/2) / R
v_outer = v · (R + B/2) / R

    两式相除，车速 v 被消掉：

    v_outer / v_inner = (R + B/2) / (R - B/2)

    这个比值只由几何决定。轴距越长、轮距越窄、转角越小，比值越接近 1；反过来，大转角 + 宽轮距会让内外轮差得很明显。

    代入模型小车的数字

    这台小车的轴距约 L = 0.16 m，轮距约 B = 0.12 m。前轮打到 30°：

    R = 0.16 / tan(30°) = 0.16 / 0.5774 ≈ 0.277 m
R - B/2 = 0.217 m
R + B/2 = 0.337 m
v_outer / v_inner = 0.337 / 0.217 ≈ 1.55

    如果车速是 1 m/s，那么内侧轮约 0.78 m/s，外侧轮约 1.22 m/s。这个差异已经足够明显：用同一个 PWM 驱动两侧，转弯时内侧轮胎一定在拖。

    代码里的 120/180

    Arduino 程序没有编码器，也没有闭环，它把几何关系翻译成固定的 PWM 占空比：

    动作左轮 PWM右轮 PWM舵机角度
    前进18018090°
    后退180（反转）180（反转）90°
    左转12018045°
    右转180120135°

    左转时内侧是左轮，120 / 180 = 0.667；我们上面算出的理论比值是 0.217 / 0.337 ≈ 0.643。两者很接近，这不是巧合——120/180 这组数就是按“内侧约等于外侧的三分之二”选出来的。

    但要注意它只是开环映射，不是实时计算：

    • 没有轮速传感器，PWM 与实际转速的关系会随电池电压、地面摩擦、载荷变化；
    • 舵机角度是开环给定，45°/90°/135° 对应的真实前轮转角并没有标定；
    • 电机有死区，低占空比时可能转不动，高占空比时又可能饱和；
    • 转弯时内外轮载荷转移，摩擦力不同，同样的 PWM 得到的转速不一定成比例。

    所以这台小车能演示“内外轮应该不一样快”，但还不能称为一个电子差速控制器。

    如果要闭环

    最小的闭环版本需要三样东西：

    1. 后轮编码器：测左右轮实际转速，做两个速度环 PID；
    2. 前轮角度反馈：电位器或绝对值编码器，替代“舵机写 45° 就假设前轮转 30°”；
    3. 目标轮速比：用实测转角实时计算 (R + B/2) / (R - B/2)，再分配给左右轮目标转速。

    控制结构可以写成：

    δ_measured → R = L / tan(δ)
           → v_inner* = v* · (R - B/2) / R
           → v_outer* = v* · (R + B/2) / R
           → 左右轮速度 PID → PWM

    这时电子差速才真正开始处理“打滑、载荷转移、电池电压下降”这些现实问题。开环的 120/180 是一个很好的教学起点，但它把“几何关系”和“执行器特性”混在了一起；闭环把两者拆开，几何负责目标，PID 负责跟踪。

    一个容易被忽略的细节：转弯半径不是常数

    上面的 R = L / tan(δ) 假设前轮转角固定、车辆稳态转弯。实际打方向盘时 δ 在变化，R 也随之变化；如果左右轮速比按固定值给，车辆在进入和退出弯道时会有短暂的拖拽。

    这也是为什么真实车辆的电子差速通常会和横摆角速度、方向盘转角、轮速传感器一起工作，而不是只查一张“转角—占空比”表。

    小结

    电子差速的数学部分其实很轻：一个转弯半径公式，一个比例分配。难的是执行——你要知道轮子实际转多快，才能决定给多少 PWM。模型小车用 120/180 把原理跑通了；下一步该补的不是更复杂的公式，而是传感器和反馈。
