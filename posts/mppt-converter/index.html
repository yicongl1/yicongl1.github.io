SEPIC 为什么适合光伏：变换器选择与四种 MPPT 算法

    项目代码与报告：https://github.com/yicongl1/MPPT-direct

    MPPT 算法本身只是“决定往哪走”，真正执行的是 DC-DC 变换器。这篇讲两件事：为什么 BA04 项目选了 SEPIC，以及报告里四种算法各自的假设和代价。

    变换器在 MPPT 里到底做什么

    光伏组件的输出阻抗随辐照度、温度变化。MPPT 控制器改变变换器的占空比 d，等价于改变组件看到的等效负载，从而把工作点推到 MPP。

    所以变换器不是“可选的外围电路”，它决定了：

    • 工作点能不能覆盖到 MPP（输入电压范围）；
    • 占空比变化对工作点的影响有多灵敏；
    • 输出电压的极性和范围能不能接后级。

    五种拓扑的取舍

    拓扑电压关系输出极性特点
    Buck只能降压同相简单、效率高；输入电压必须始终高于输出
    Boost只能升压同相简单；输入电压必须始终低于输出
    Buck-Boost可升可降反相范围宽；输出是负压，后级要处理
    Cuk可升可降反相输入输出电流都连续；同样是负压
    SEPIC可升可降同相范围宽、极性友好；器件比 Buck/Boost 多

    光伏的麻烦在于输入电压大幅波动：辐照度低时组件电压下降，温度高时电压也下降。如果固定一个输出电压：

    • 用 Buck，低辐照时输入可能低于输出，占空比顶到 1 也追不上；
    • 用 Boost，高辐照时输入可能高于输出，根本没法工作；
    • 用 Buck-Boost 或 Cuk，范围够了，但输出反相，后级需要额外处理；
    • 用 SEPIC，既能升也能降，输出还与输入同相。

    这就是项目选 SEPIC 的直接原因：宽输入范围 + 同相输出。代价是多了两个电感、两个电容和一个开关管，损耗和体积都上去了。

    SEPIC 的两个阶段

    SEPIC 的工作可以粗略分成两段：

    1. 开关导通：输入电感 L1 直接跨在输入上储能；耦合电容 C1 通过第二个电感 L2 放电，L2 也储能；二极管截止，负载由输出电容供电。
    2. 开关关断：L1 和 L2 的电流经二极管流向输出，同时给 C1 充电；负载得到能量。

    理想情况下，输出电压与占空比的关系是：

    Vout / Vin = d / (1 - d)

    d = 0.5 时输出等于输入，小于 0.5 降压，大于 0.5 升压。实际设计还要考虑二极管压降、电感铜损、开关损耗和电容 ESR。

    一个容易被忽略的细节：仿真步长

    项目的仿真步长是 2 s，而 SEPIC 的开关频率通常在几十到几百 kHz。2 s 的步长不可能逐开关周期仿真，所以模型必然是平均化或行为级的：它描述的是占空比到输出电压/电流的平均关系，而不是每个开关周期的纹波。

    这带来两个后果：

    • 仿真快，适合跑 366 天；
    • 看不到开关纹波、二极管反向恢复这类高频细节，效率也只能用“能量比”近似，而不是从器件损耗模型算出来。

    做 MPPT 算法对比时这没问题，因为算法关心的是秒级的功率走向；但如果要评估变换器本身，就必须换成开关级模型。

    报告里的四种算法

    算法步长需要测量优点代价
    P&O固定V、I简单、不依赖模型稳态振荡；突变时方向判断滞后
    INC固定V、I（精度要求高）理论上更接近 MPP、振荡更小计算与采样要求更高，噪声敏感
    P&OA可变V、I（或 V*）收敛快、稳态振荡小需要整定 α，参数依赖工况
    模糊逻辑可变误差 E 与误差变化 DE适合非线性、参数不确定规则表和隶属函数需要设计经验

    INC 的判据

    对 P = V·I 求导：

    dP/dV = V · dI/dV + I

    MPP 处 dP/dV = 0，于是：

    dI/dV = -I/V

    按这个关系判断工作点在 MPP 左侧还是右侧：

    • dI/dV > -I/V：在左侧，升压；
    • dI/dV < -I/V：在右侧，降压；
    • 相等：已经在 MPP。

    当 ΔV = 0 时，改用电流变化判断。理论上它比 P&O 更准，但 dI/dV 是两个相近数相减再相除，采样噪声会被放大。

    模糊逻辑的骨架

    模糊控制把“误差大/小”变成语言变量：

    • 输入：误差 E 和误差变化 DE；输出：占空比增量；
    • 五个模糊集：NB、NS、Z、PS、PB；
    • 隶属函数取钟形：
    μ(x) = 1 / (1 + ((x - c) / a)²)
    • 推理用 Mamdani，合取用 min；
    • 去模糊化用重心法：
    z = Σ μ(zᵢ)·zᵢ / Σ μ(zᵢ)

    它不依赖精确的组件模型，但规则表、隶属函数宽度和输出比例因子都要调，调参成本比 P&O 高得多。

    怎么选

    如果只做课程作业或低成本控制器：

    • P&O 足够，前提是步长别太大，并且接受稳态振荡；
    • 想要更稳的稳态，用 INC，但要保证采样精度和滤波；
    • 工况变化剧烈（云、遮挡），考虑 变步长 P&OA 或 P&O + INC 的混合；
    • 组件老化、参数不确定、强非线性，才值得上 模糊逻辑。

    没有一种算法在所有指标上都赢。BA04 的结论也类似：全年发电量上 P&O 和 P&OA 只差 0.5%，真正的差异在暂态和稳态波动里——这也说明选算法之前，先想清楚你要优化的是哪个指标。
